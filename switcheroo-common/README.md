# switcheroo-common

Provides shared types for the [`switcheroo-daemon`](https://crates.io/crates/switcheroo-daemon) and [`switcherooctl`](https://crates.io/crates/switcherooctl) crates.

> [!TIP]
> This crate is intended to be used internally by the `switcheroo-control-rs` workspace. Most users should interact with [`switcherooctl`](https://crates.io/crates/switcherooctl) and [`switcheroo-daemon`](https://crates.io/crates/switcheroo-daemon) instead.
